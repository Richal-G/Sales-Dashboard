# Sales-Dashboard


📊 Madhav E-Commerce Sales Dashboard

An interactive E-Commerce Sales Dashboard built using Microsoft Power BI to analyze sales, profit, quantity, customers, payment methods, and product performance. The dashboard provides a clear overview of business performance and helps identify key sales trends across different states, months, categories, and sub-categories.

🎯 Project Objective

The objective of this project is to transform e-commerce sales data into meaningful business insights using data visualization and interactive reporting.

📌 Key Metrics
💰 Total Sales Amount: 438K
📈 Total Profit: 37K
📦 Total Quantity: 1.5K
🛒 Average Order Value (AOV): 121K
📊 Dashboard Features
Sales & Profit Analysis – Track overall sales and profitability.
Monthly Profit Analysis – Identify profitable and loss-making months.
State-wise Analysis – Compare sales performance across different states.
Payment Mode Analysis – Analyze quantity based on different payment methods.
Category Analysis – Understand the contribution of different product categories.
Sub-Category Analysis – Identify the most profitable sub-categories.
Customer Analysis – Compare sales generated by individual customers.
Quarter & State Filters – Interactive slicers for deeper analysis.
🛠️ Tools & Technologies
Microsoft Power BI
Power Query – Data cleaning and transformation
DAX – Calculated measures and KPIs
Data Visualization
Data Analysis
💡 Key Insights

The dashboard helps identify:

Top-performing states and customers
Most profitable product sub-categories
Monthly profit fluctuations
Distribution of sales quantity across payment modes
Category-wise contribution to total quantity
Areas where profitability can be improved
