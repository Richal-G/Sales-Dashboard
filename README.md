# Sales-Dashboard
Developed an interactive E-Commerce Sales Dashboard using Power BI to analyze sales performance, customer behavior, and product trends.

1.   Analyzed total sales, profit, orders, and average order value using interactive KPIs and visualizations.
2.   Identified top-performing products, categories, regions, and customer segments to understand business performance.
3.   Used Power Query and DAX for data cleaning, transformation, calculated measures, and dynamic filtering.
4.   Designed an interactive dashboard with slicers, charts, cards, and drill-downs to enable data-driven business decisions.
